# 안용복의 뱃길 지도 (apps/hi-2/voyage-map)

「동래 사람 안용복과 펼치는 우리 반 독도 안내 책」 교사 제작 웹앱 · 잇:다 AI 러닝랩

- 쓰는 차시: 2차시(뱃길 따라가기·독도 둘러보기, 학생 개인 크롬북), 4차시(독도 모형 완성하기 — 교과서 독도 모형 만들기 활동을 대신함). 교사는 전자칠판에서 시연.
- 단계: 1 부산(동래)에서 출발 → 2 항구 고르기(강릉·묵호·죽변·포항) → 3 울릉도에서 독도로(87.4km) → 4 독도 둘러보기(지형 8곳, 옆에서 본 모습) → 5 독도 모형 완성하기(서도·동도·촛대바위·괭이갈매기·배 끌어 놓기).
- 화면의 사실: 초등 사회 5-1 교과서(사31~37, 사42)에 나온 것만 씀.
- 한 파일, 로그인·저장·외부 라이브러리 없음.

## 그림 참고와 [교사 확인]
- 서도는 서쪽, 동도는 서도의 동남쪽에 좁은 바다를 사이에 둠. 서도가 조금 더 넓고 훨씬 높음. 항공 사진의 배치·크기 비율을 보고 단순화함(해안선 자료를 직접 받을 수 없어 손으로 따라 그림).
- 위치 근거: 탕건봉 = 서도 북쪽 끝, 독립문바위 = 동도 동쪽, 한반도바위 = 동도 북쪽(경북교육청 독도 사진 자료 설명).
- **[교사 확인]** 촛대바위·코끼리바위·장군바위의 정확한 자리와 동도·서도 해안선 모양을 실제 항공 사진과 한 번 더 대조해 주세요. 고칠 곳은 `SEODO`, `DONGDO`, `SPOTS` 좌표(미터 단위, x=동쪽, y=남쪽)만 바꾸면 됨.
