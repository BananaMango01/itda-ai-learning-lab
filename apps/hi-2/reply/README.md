# 안용복의 답장 (apps/hi-2/reply) — 교사용, 코드 사본

「동래 사람 안용복과 펼치는 우리 반 독도 안내 책」 · 잇:다 AI 러닝랩

학생 설명하는 글 초고(사진·받아쓰기·붙여 넣기)를 넣으면 제미나이가 루브릭(내용 선정·글의 구조·글의 짜임·독자 고려)에 맞춘 **피드백 초안**을 만들고, 교사가 고친 뒤 **답장 카드**로 인쇄합니다. 6~7차시, 교사만 사용. 학생은 쓰지 않습니다.

**이 폴더는 코드 사본입니다. 실제 실행은 선생님 구글 계정의 앱스 스크립트에서 합니다. API 키·학생 글을 이 저장소에 절대 올리지 않습니다.**

## 설치 (약 10분)
1. script.google.com → **새 프로젝트** → 왼쪽 `Code.gs`에 이 폴더의 `Code.gs`를 통째로 붙여 넣기
2. 왼쪽 파일 옆 **+** → **HTML** → 이름 `index` → 이 폴더의 `index.html`을 통째로 붙여 넣기 → 저장
3. Google AI Studio(aistudio.google.com)에서 **API 키 만들기** → 키 복사
4. 앱스 스크립트 왼쪽 **프로젝트 설정(톱니바퀴)** → **스크립트 속성** → **스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값에 키 붙여 넣기 → 저장
5. 오른쪽 위 **배포** → **새 배포** → 유형 **웹 앱** → 실행 사용자 **나**, 액세스 권한 **나만** → **배포** → 권한 허용
6. 나온 웹 앱 주소를 즐겨찾기(학생에게 주지 않음)

[교사 확인] 화면 메뉴 이름은 구글이 바꿀 수 있어요. 학교 계정에서 AI Studio가 막혀 있으면 개인 계정 키를 쓰거나 '프롬프트 복사' 모드를 씁니다.

## 쓰는 법
학생 번호·맡은 장·읽을 사람 고르기 → 사진/받아쓰기/붙여 넣기로 글 넣기 → 피드백 만들기 → 모든 칸을 읽고 고치기 → 답장 카드 인쇄(A4 한 장에 4장).
- 학생 이름은 넣지 않습니다(번호만).
- 키가 없거나 막히면 **프롬프트 복사** → 제미나이 화면에 붙여 넣기 → 나온 JSON을 다시 붙여 넣기.

## 시험 글(가상의 글, 이름 없음)
| 예상 | 글 | 나와야 할 것 |
|---|---|---|
| 상 | 열거 구조로 괭이갈매기·해국·좋은 어장을 출처와 함께 설명 | 수준 상, 사실 확인 모두 맞음 |
| 중 | 순서 구조로 1454·1900 기록을 쓰되 이음말이 약함 | 수준 중, 고칠 점에 이음말 |
| 하 | "독도는 강원도에 있다." 포함 짧은 글 | 사실 확인에서 '다름, 사31' |

## 문제가 생기면
- 401·403: 키 확인 / 429: 잠시 뒤 다시 / 모델 이름 오류: `Code.gs` 맨 위 `MODEL`을 AI Studio 목록에 있는 이름으로 바꿈
- 시험은 API로만 하므로 선생님 제미나이 대화 목록에 시험 대화가 남지 않습니다.
